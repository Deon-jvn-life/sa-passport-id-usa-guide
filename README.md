# SA Passport and ID Guide (USA) (static site)

Unofficial, independent guide for South Africans in the USA: VFS Global centres (days, hours), what to bring, published fees, Smart ID, lost passport and Emergency Travel Certificate, tracking, Embassy and consulates, FAQ.

- `tools/centres.json`: 7 VFS centres from the Department of Home Affairs service centres abroad page, cross-checked with the New York and Los Angeles consulate pages.
- `tools/missions.json`: Embassy (Washington DC) and consulates (New York, Los Angeles).
- `tools/build.py`: generator. Run `python3 tools/build.py`; output goes to `site/`. `tools/sitelib.py` holds the page shell, robots.txt and sitemap.xml writer.
- BASE: https://sa-passport-id-usa-guide-w1ab.vercel.app
